This page runs the JavaScript package in your browser, so nothing you paste leaves it. The Python
package and the Rust crate pass the same fixtures and give the same output on every fixture input
([one Unicode note](/trackparse/project/ports/#what-the-rust-port-taught) for Rust). The code panels
show the call in all three languages.

The URL updates as you type, so you can copy it to share an input, like
[`"Numb" by Linkin Park` in youtube mode](/trackparse/playground/#track=%22Numb%22%20by%20Linkin%20Park&mode=youtube).
