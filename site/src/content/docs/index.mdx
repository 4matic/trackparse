## Extract, don't delete

Most title parsers split on the dash, hand you `["Wilkinson ft. Becky Hill", "Afterglow (Sub Focus VIP Remix)"]` and call it a day. Others "clean" the string and throw the feat and the remix away. You lose exactly the parts you probably wanted.

trackparse keeps everything. Each piece it recognises goes into a field with a label on it, and anything it doesn't recognise stays in the title, word for word. If you only want a clean title, it's there. If you want to know that Sub Focus did a VIP remix, that's there too.

## Same call, same answer

<Tabs syncKey="lang">
  <TabItem label="JavaScript">
    ```js
    import { parse } from "trackparse";

    const track = parse("Noisia feat. Foreign Beggars - Shellshock");
    track.artists.map((a) => `${a.name} (${a.role})`);
    // [ 'Noisia (primary)', 'Foreign Beggars (featured)' ]

    parse("Queen - Bohemian Rhapsody (Live at Wembley 1986)").versions[0];
    // { type: 'live', descriptor: 'at Wembley', year: 1986, … }
    ```
  </TabItem>
  <TabItem label="Python">
    ```python
    from trackparse import parse

    track = parse("Noisia feat. Foreign Beggars - Shellshock")
    [f"{a.name} ({a.role})" for a in track.artists]
    # ['Noisia (primary)', 'Foreign Beggars (featured)']

    parse("Queen - Bohemian Rhapsody (Live at Wembley 1986)").versions[0]
    # Version(type='live', ..., descriptor='at Wembley', year=1986, ...)
    ```
  </TabItem>
</Tabs>
