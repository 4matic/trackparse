The same string can mean different things depending on where it came from.
`Blink-182-All The Small Things` is clearly artist and title on YouTube. In a music library, a
tight dash like that is more likely part of a name. Modes tell trackparse how much guessing the
source can take.

| Mode | For | What it adds |
|---|---|---|
| `clean` | store metadata, ID3 tags | Only a spaced dash separates artist and title |
| `youtube` | video titles, scrobbles | Pipe segments, `"Title" by Artist`, `Artist: "Title"`, unspaced dashes, trailing junk, the uploader fallback |
| `filename` | files on disk | Strips the extension, reads `_` as a space, accepts `01-Track` numbering |
| `tracklist` | one line of a tracklist | The first spaced dash always separates, and the words after it are never read as a version or genre suffix |
| `auto` | anything (the default) | Picks `filename`, `youtube` or `clean` from the string. It never picks `tracklist` |

The resolved mode is in `track.mode`, so you can always see which one ran. You pick one with the
[`mode` option](/trackparse/reference/options/#parse-options). In Rust the option is the enum
[`ModeOption`](https://docs.rs/trackparse/latest/trackparse/enum.ModeOption.html) and the resolved mode is [`Mode`](https://docs.rs/trackparse/latest/trackparse/enum.Mode.html),
which has no `Auto`. In Go both are the string type [`Mode`](https://pkg.go.dev/github.com/4matic/trackparse/go#Mode):
[`trackparse.ModeAuto`](https://pkg.go.dev/github.com/4matic/trackparse/go#ModeAuto) (`"auto"`) asks for auto, an empty `Mode` in `ParseOptions`
means auto too, and `Track.Mode` is never `ModeAuto`. The mode rules are
[R2](/trackparse/reference/spec/#r2-mode-prelude) in the spec.

## How auto decides

1. A known audio or video extension at the end (`.mp3`, `.flac`, `.wav`, `.mp4`…) means
   `filename`.
2. Junk, a `|`, or a platform suffix like `- YouTube` means `youtube`.
3. Anything else is `clean`.

That order is [R2.1](/trackparse/reference/spec/#r2-mode-prelude:~:text=R2.1%20Resolution). Open the
[file name](/trackparse/playground/#track=07_Burial_-_Archangel.mp3) or the [video title](/trackparse/playground/#track=Noisia%20-%20Stigma%20%7C%20Official%20Video)
in the playground to see the mode it picks.

<Tabs syncKey="lang">
<TabItem label="JavaScript">

```js
import { parse } from "trackparse";

const file = parse("07_Burial_-_Archangel.mp3");
[file.mode, file.position, file.artists[0].name, file.title];
// [ 'filename', { raw: '07', number: 7 }, 'Burial', 'Archangel' ]

const video = parse("Noisia - Stigma | Official Video");
[video.mode, video.title, video.junk];
// [ 'youtube', 'Stigma', [ { raw: 'Official Video', kind: 'video' } ] ]
```

</TabItem>
<TabItem label="Python">

```python
from trackparse import parse

file = parse("07_Burial_-_Archangel.mp3")
(file.mode, file.position, file.artists[0].name, file.title)
# ('filename', Position(raw='07', number=7), 'Burial', 'Archangel')

video = parse("Noisia - Stigma | Official Video")
(video.mode, video.title, video.junk)
# ('youtube', 'Stigma', (Junk(raw='Official Video', kind='video'),))
```

</TabItem>
<TabItem label="Rust">

```rust
use trackparse::parse;

let file = parse("07_Burial_-_Archangel.mp3");
(file.mode, &file.position, &file.artists[0].name, &file.title);
// (Filename, Some(Position { raw: "07", number: 7 }), "Burial", "Archangel")

let video = parse("Noisia - Stigma | Official Video");
(video.mode, &video.title, &video.junk);
// (Youtube, "Stigma", [Junk { raw: "Official Video", kind: Video }])
```

</TabItem>
<TabItem label="Go">

```go
import (
    "fmt"

    "github.com/4matic/trackparse/go"
)

t := trackparse.Parse("07_Burial_-_Archangel.mp3")
fmt.Println(t.Mode, t.Position.Number, t.Artists[0].Name, "/", t.Title)
// filename 7 Burial / Archangel

t = trackparse.Parse("Noisia - Stigma | Official Video")
fmt.Printf("%s %q %+v\n", t.Mode, t.Title, t.Junk)
// youtube "Stigma" [{Raw:Official Video Kind:video}]
```

## youtube mode

Set it yourself when you know the strings are video titles. It takes guesses that `clean`
won't, and every guess shows up in [`warnings`](/trackparse/reference/warnings/#track-warnings). The
three below are [R6.6](/trackparse/reference/spec/#r6-artisttitle-separator:~:text=R6.6%20by%20%28youtube%20only%29),
[R6.5](/trackparse/reference/spec/#r6-artisttitle-separator:~:text=R6.5%20Quoted%20title) and [R6.7](/trackparse/reference/spec/#r6-artisttitle-separator:~:text=R6.7%20Unspaced%20dash); pipes are
[R2.4](/trackparse/reference/spec/#r2-mode-prelude:~:text=R2.4%20youtube%20pipes):

<Tabs syncKey="lang">
<TabItem label="JavaScript">

```js
const show = (t) => [t.artists.map((a) => a.name), t.title, t.warnings];

show(parse('"Numb" by Linkin Park', { mode: "youtube" }));
// [ [ 'Linkin Park' ], 'Numb', [ 'bySplit' ] ]

show(parse('Linkin Park: "Numb"', { mode: "youtube" }));
// [ [ 'Linkin Park' ], 'Numb', [ 'quotedTitleSplit' ] ]

show(parse("Blink-182-All The Small Things", { mode: "youtube" }));
// [ [ 'Blink-182' ], 'All The Small Things', [ 'unspacedDashSplit' ] ]
```

</TabItem>
<TabItem label="Python">

```python
def show(t):
    return [a.name for a in t.artists], t.title, t.warnings

show(parse('"Numb" by Linkin Park', mode="youtube"))
# (['Linkin Park'], 'Numb', ('bySplit',))

show(parse('Linkin Park: "Numb"', mode="youtube"))
# (['Linkin Park'], 'Numb', ('quotedTitleSplit',))

show(parse("Blink-182-All The Small Things", mode="youtube"))
# (['Blink-182'], 'All The Small Things', ('unspacedDashSplit',))
```

</TabItem>
<TabItem label="Rust">

```rust
use trackparse::{parse_with, ModeOption, ParseOptions, ParsedTrack};

let show = |t: ParsedTrack| (t.artists.into_iter().map(|a| a.name).collect::<Vec<_>>(), t.title, t.warnings);
let youtube = ParseOptions::new().mode(ModeOption::Youtube);

show(parse_with("\"Numb\" by Linkin Park", &youtube));
// (["Linkin Park"], "Numb", [BySplit])

show(parse_with("Linkin Park: \"Numb\"", &youtube));
// (["Linkin Park"], "Numb", [QuotedTitleSplit])

show(parse_with("Blink-182-All The Small Things", &youtube));
// (["Blink-182"], "All The Small Things", [UnspacedDashSplit])
```

</TabItem>
<TabItem label="Go">

```go
youtube := trackparse.ParseOptions{Mode: trackparse.ModeYouTube}

t = trackparse.ParseWith(`"Numb" by Linkin Park`, youtube)
fmt.Printf("%q %q %v\n", t.Artists[0].Name, t.Title, t.Warnings)
// "Linkin Park" "Numb" [bySplit]

t = trackparse.ParseWith(`Linkin Park: "Numb"`, youtube)
fmt.Printf("%q %q %v\n", t.Artists[0].Name, t.Title, t.Warnings)
// "Linkin Park" "Numb" [quotedTitleSplit]

t = trackparse.ParseWith("Blink-182-All The Small Things", youtube)
fmt.Printf("%q %q %v\n", t.Artists[0].Name, t.Title, t.Warnings)
// "Blink-182" "All The Small Things" [unspacedDashSplit]
```

</TabItem>
</Tabs>

In `clean` mode the last one comes back with no artist, the whole string as the title and a
[`noSeparator`](/trackparse/reference/warnings/#track-warnings:~:text=noSeparator) warning. That's the safe answer when you can't be sure. Compare the two in the
playground:
[youtube](/trackparse/playground/#track=Blink-182-All%20The%20Small%20Things&mode=youtube) and
[clean](/trackparse/playground/#track=Blink-182-All%20The%20Small%20Things&mode=clean).

### The uploader fallback

Many music videos are titled with only the song name, and the artist is the channel. Pass the
channel as [`uploader`](/trackparse/reference/options/#parse-options) and youtube mode uses it when there's no separator. Auto-generated suffixes
like `- Topic` and `VEVO` are dropped ([R6.8](/trackparse/reference/spec/#r6-artisttitle-separator:~:text=R6.8%20No%20separator);
[try it](/trackparse/playground/#track=Around%20the%20World&mode=youtube&uploader=Daft%20Punk%20-%20Topic)):

<Tabs syncKey="lang">
<TabItem label="JavaScript">

```js
show(parse("Around the World", { mode: "youtube", uploader: "Daft Punk - Topic" }));
// [ [ 'Daft Punk' ], 'Around the World', [] ]
```

</TabItem>
<TabItem label="Python">

```python
show(parse("Around the World", mode="youtube", uploader="Daft Punk - Topic"))
# (['Daft Punk'], 'Around the World', ())
```

</TabItem>
<TabItem label="Rust">

```rust
let options = ParseOptions::new().mode(ModeOption::Youtube).uploader("Daft Punk - Topic");
show(parse_with("Around the World", &options));
// (["Daft Punk"], "Around the World", [])
```

</TabItem>
<TabItem label="Go">

```go
options := trackparse.ParseOptions{Mode: trackparse.ModeYouTube, Uploader: "Daft Punk - Topic"}
t = trackparse.ParseWith("Around the World", options)
fmt.Printf("%q %q\n", t.Artists[0].Name, t.Title)
// "Daft Punk" "Around the World"
```

</TabItem>
</Tabs>

## filename mode

The extension comes off first, and a name without spaces gets its underscores turned into spaces
([R2.3](/trackparse/reference/spec/#r2-mode-prelude:~:text=R2.3%20filename)). A leading number then
counts as a track number in more forms than elsewhere, such as `311 - ` and `01-Track` ([R4.2](/trackparse/reference/spec/#r4-prefixes-timestamp-and-position:~:text=R4.2%20Position)). Try
[the first line](/trackparse/playground/#track=02_Aphex_Twin_-_Xtal.flac) in the playground.

<Tabs syncKey="lang">
<TabItem label="JavaScript">

```js
parse("02_Aphex_Twin_-_Xtal.flac").artists[0].name;   // 'Aphex Twin'
parse("311 - Amber.mp3").position;                     // { raw: '311', number: 311 }
parse("311 - Amber").artists[0].name;                  // '311'
```

</TabItem>
<TabItem label="Python">

```python
parse("02_Aphex_Twin_-_Xtal.flac").artists[0].name    # 'Aphex Twin'
parse("311 - Amber.mp3").position                      # Position(raw='311', number=311)
parse("311 - Amber").artists[0].name                   # '311'
```

</TabItem>
<TabItem label="Rust">

```rust
&parse("02_Aphex_Twin_-_Xtal.flac").artists[0].name;  // "Aphex Twin"
parse("311 - Amber.mp3").position;                     // Some(Position { raw: "311", number: 311 })
&parse("311 - Amber").artists[0].name;                 // "311"
```

</TabItem>
<TabItem label="Go">

```go
fmt.Printf("%q\n", trackparse.Parse("02_Aphex_Twin_-_Xtal.flac").Artists[0].Name)   // "Aphex Twin"
fmt.Printf("%+v\n", *trackparse.Parse("311 - Amber.mp3").Position)             // {Raw:311 Number:311}
fmt.Printf("%q\n", trackparse.Parse("311 - Amber").Artists[0].Name)            // "311"
```

</TabItem>
</Tabs>

The `311` lines show why the mode matters. In a file name a leading number with a dash is a track
number. Anywhere else, `311` could be a band.

## tracklist mode

Inside a tracklist almost every line is `Artist - Title`, so the first spaced dash can be trusted
([R6.10](/trackparse/reference/spec/#r6-artisttitle-separator:~:text=R6.10%20Tracklist%20mode), [R13.6](/trackparse/reference/spec/#r136-tracklist-mode)).
A single string doesn't get that benefit of the doubt:

<Tabs syncKey="lang">
<TabItem label="JavaScript">

```js
const plain = parse("Electrosoul System - Liquid Metal");
[plain.artists, plain.title, plain.junk];
// [ [], 'Electrosoul System', [ { raw: 'Liquid Metal', kind: 'genre' } ] ]

show(parse("Electrosoul System - Liquid Metal", { mode: "tracklist" }));
// [ [ 'Electrosoul System' ], 'Liquid Metal', [] ]
```

</TabItem>
<TabItem label="Python">

```python
plain = parse("Electrosoul System - Liquid Metal")
(plain.artists, plain.title, plain.junk)
# ((), 'Electrosoul System', (Junk(raw='Liquid Metal', kind='genre'),))

show(parse("Electrosoul System - Liquid Metal", mode="tracklist"))
# (['Electrosoul System'], 'Liquid Metal', ())
```

</TabItem>
<TabItem label="Rust">

```rust
let plain = parse("Electrosoul System - Liquid Metal");
(&plain.artists, &plain.title, &plain.junk);
// ([], "Electrosoul System", [Junk { raw: "Liquid Metal", kind: Genre }])

show(parse_with("Electrosoul System - Liquid Metal", &ParseOptions::new().mode(ModeOption::Tracklist)));
// (["Electrosoul System"], "Liquid Metal", [])
```

</TabItem>
<TabItem label="Go">

```go
t = trackparse.Parse("Electrosoul System - Liquid Metal")
fmt.Printf("%q %+v\n", t.Title, t.Junk)
// "Electrosoul System" [{Raw:Liquid Metal Kind:genre}]

t = trackparse.ParseWith("Electrosoul System - Liquid Metal", trackparse.ParseOptions{Mode: trackparse.ModeTracklist})
fmt.Printf("%q %q\n", t.Artists[0].Name, t.Title)
// "Electrosoul System" "Liquid Metal"
```

</TabItem>
</Tabs>

[`parseTracklist`](/trackparse/guides/tracklists/) (`parse_tracklist` in Python and Rust, `ParseTracklist` in Go) uses this
mode for every line. You only need to set it yourself when you parse tracklist lines one at a time.
The playground can show [this line in tracklist mode](/trackparse/playground/#track=Electrosoul%20System%20-%20Liquid%20Metal&mode=tracklist).
[Tracklist mode](/trackparse/guides/tracklists/#tracklist-mode) in the tracklist guide has more
lines that need it.
