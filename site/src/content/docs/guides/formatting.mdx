`format(track, options?)` renders a parsed track back to a string. In Python it is
`format_track(track, **options)`. In Rust it is `format_track(&track)`, or
`format_track_with(&track, &options)` with options. In Go it is `trackparse.Format(track)`, or
`trackparse.FormatWith(track, options)`. Use it to bring a messy library to one style,
or to build a display title without the junk.

const t = parse(

Junk is never written back. Everything else is, by default, the way it was written.

## Options

| Option | Values | Default |
|---|---|---|
| `feat` | `"source"` keep features where they were, `"artist"` move them left of the dash, `"title"` move them into the title, `"omit"` drop them | `"source"` |
| `featMarker` | the word to write before features | the one from the input |
| `joiners` | `"original"` as written, `"canonical"` normalized (`and` → `&`, `;` → `,`, `ft.` → `feat.`) | `"original"` |
| `versions` | `"all"` or `"none"` | `"all"` |
| `producers` | write `(prod. by …)` credits | `true` |
| `position` | write the track number back | `false` |

Python takes the options as keyword arguments, so `featMarker` is `feat_marker`. Rust takes a
`FormatOptions` value built with one setter per option, and the values are enums. Go takes a
`FormatOptions` struct whose zero value is the default, and the values are typed string constants.
Since a Go `bool` field defaults to `false`, `producers` becomes `OmitProducers`:

| Option | Python | Rust | Go |
|---|---|---|---|
| `feat` | `feat="title"` | `.feat(FeatPlacement::Title)`: `Source`, `Artist`, `Title`, `Omit` | `Feat: trackparse.FeatTitle`: `FeatSource`, `FeatArtist`, `FeatTitle`, `FeatOmit` |
| `featMarker` | `feat_marker="featuring"` | `.feat_marker("featuring")` | `FeatMarker: trackparse.Ptr("featuring")` (a `*string`) |
| `joiners` | `joiners="canonical"` | `.joiners(JoinerStyle::Canonical)`: `Original`, `Canonical` | `Joiners: trackparse.JoinersCanonical`: `JoinersOriginal`, `JoinersCanonical` |
| `versions` | `versions="none"` | `.versions(VersionsOption::None)`: `All`, `None` | `Versions: trackparse.VersionsNone`: `VersionsAll`, `VersionsNone` |
| `producers` | `producers=False` | `.producers(false)` | `OmitProducers: true` |
| `position` | `position=True` | `.position(true)` | `Position: true` |

<TabItem label="JavaScript">

```js
format(t, { feat: "title" });
// 'Wilkinson - Afterglow (ft. Becky Hill & Tom Cane) (Sub Focus VIP Remix)'

format(t, { feat: "title", joiners: "canonical" });
// 'Wilkinson - Afterglow (feat. Becky Hill & Tom Cane) (Sub Focus VIP Remix)'

format(t, { feat: "artist", featMarker: "featuring" });
// 'Wilkinson featuring Becky Hill & Tom Cane - Afterglow (Sub Focus VIP Remix)'

format(t, { feat: "omit" });       // 'Wilkinson - Afterglow (Sub Focus VIP Remix)'
format(t, { versions: "none" });   // 'Wilkinson ft. Becky Hill & Tom Cane - Afterglow'
format(t, { position: true });     // '01. Wilkinson ft. Becky Hill & Tom Cane - Afterglow (Sub Focus VIP Remix)'

format(parse("Future - Mask Off (prod. by Metro Boomin)"), { producers: false });
// 'Future - Mask Off'
```

use trackparse::{format_track_with, FeatPlacement, FormatOptions, JoinerStyle, VersionsOption};

format_track_with(&t, &FormatOptions::new().feat(FeatPlacement::Title));

format_track_with(&t, &FormatOptions::new().feat(FeatPlacement::Artist).feat_marker("featuring"));

format_track_with(&t, &FormatOptions::new().feat(FeatPlacement::Omit));

format_track_with(&t, &FormatOptions::new().versions(VersionsOption::None));
// "Wilkinson ft. Becky Hill & Tom Cane - Afterglow"

## Round trip

Parsing the formatted string gives back the same artist names and roles, the same title and the
same version types and remixers, as long as the first parse raised no warnings. The spec makes this
an invariant (R11.6, under [R11](/trackparse/reference/spec/#r11-format)), and the
[property tests](/trackparse/project/testing/#properties) check it on generated input:

<Tabs syncKey="lang">
<TabItem label="JavaScript">

```js
const s = "Noisia feat. Foreign Beggars - Shellshock (Phace Remix)";
// same artists, title and versions as parse(s):
const again = parse(format(parse(s)));
again.fullTitle;   // 'Shellshock (Phace Remix)'
```

</TabItem>

s = "Noisia feat. Foreign Beggars - Shellshock (Phace Remix)"
