import { Tabs, TabItem } from "@astrojs/starlight/components";

[`format(track, options?)`](/trackparse/reference/functions/#formattrack-options) renders a parsed
track back to a string. In Python it is `format_track(track, **options)`. In Rust it is
[`format_track(&track)`](https://docs.rs/trackparse/latest/trackparse/fn.format_track.html), or
[`format_track_with(&track, &options)`](https://docs.rs/trackparse/latest/trackparse/fn.format_track_with.html) with options. In Go it is
[`trackparse.Format(track)`](https://pkg.go.dev/github.com/4matic/trackparse/go#Format), or [`trackparse.FormatWith(track, options)`](https://pkg.go.dev/github.com/4matic/trackparse/go#FormatWith).
In C it is `trackparse_format(track)`, or `trackparse_format_with(track, options)`, and the
string it returns is freed with `trackparse_string_free`
([`trackparse.h`](https://github.com/4matic/trackparse/blob/main/c/include/trackparse.h)).
Use it to bring a messy library to one style, or to build a display title without the junk. The
rules are [R11](/trackparse/reference/spec/#r11-format) in the spec.

Junk is never written back. Everything else is, by default, the way it was written. The
[playground](/trackparse/playground/#track=01.%20Wilkinson%20ft.%20Becky%20Hill%20%26%20Tom%20Cane%20-%20Afterglow%20%28Sub%20Focus%20VIP%20Remix%29%20%5BOfficial%20Video%5D) has a `format()` panel with this track loaded.

## Options

| Option | Values | Default |
|---|---|---|
| `feat` | `"source"` keep features where they were, `"artist"` move them left of the dash, `"title"` move them into the title, `"omit"` drop them ([R11.2](/trackparse/reference/spec/#r11-format:~:text=R11.2%20Featured)) | `"source"` |
| `featMarker` | the word to write before features | the one from the input |
| `joiners` | `"original"` as written, `"canonical"` normalized (`and` → `&`, `;` → `,`, `ft.` → `feat.`; [R11.5](/trackparse/reference/spec/#r11-format:~:text=R11.5%20canonical%20joiners)) | `"original"` |
| `versions` | `"all"` or `"none"` | `"all"` |
| `producers` | write `(prod. by …)` credits | `true` |
| `position` | write the track number back | `false` |
| `label` | write the [label](/trackparse/guides/junk-and-flags/#labels-after-a-bullet) back after the title, ` • VISION` ([R11.3](/trackparse/reference/spec/#r11-format:~:text=R11.3%20Title)) | `true` |

Python takes the options as keyword arguments, so `featMarker` is `feat_marker`. Rust takes a
[`FormatOptions`](https://docs.rs/trackparse/latest/trackparse/struct.FormatOptions.html) value built with one setter per option, and the
values are enums ([`FeatPlacement`](https://docs.rs/trackparse/latest/trackparse/enum.FeatPlacement.html),
[`JoinerStyle`](https://docs.rs/trackparse/latest/trackparse/enum.JoinerStyle.html), [`VersionsOption`](https://docs.rs/trackparse/latest/trackparse/enum.VersionsOption.html)). Go
takes a [`FormatOptions`](https://pkg.go.dev/github.com/4matic/trackparse/go#FormatOptions) struct whose zero value is the default, and the values
are typed string constants ([`FeatPlacement`](https://pkg.go.dev/github.com/4matic/trackparse/go#FeatPlacement), [`JoinerStyle`](https://pkg.go.dev/github.com/4matic/trackparse/go#JoinerStyle),
[`VersionsOption`](https://pkg.go.dev/github.com/4matic/trackparse/go#VersionsOption)); [`trackparse.Ptr`](https://pkg.go.dev/github.com/4matic/trackparse/go#Ptr) sets `FeatMarker`.
Since a Go `bool` field defaults to `false`, `producers` becomes `OmitProducers` and `label`
becomes `OmitLabel`. C takes a
`trackparse_format_options` handle from `trackparse_format_options_new()`, with one setter per
option and C enums for the values; an option you don't set keeps its default, and
`trackparse_format_options_free` releases the handle. Each tab below starts with the names in
that language.

<TabItem label="JavaScript">

The names and values are those of the table above, as keys of one object.

```js
format(t, { feat: "title" });
// 'Wilkinson - Afterglow (ft. Becky Hill & Tom Cane) (Sub Focus VIP Remix)'

format(t, { feat: "title", joiners: "canonical" });
// 'Wilkinson - Afterglow (feat. Becky Hill & Tom Cane) (Sub Focus VIP Remix)'

format(t, { feat: "artist", featMarker: "featuring" });
// 'Wilkinson featuring Becky Hill & Tom Cane - Afterglow (Sub Focus VIP Remix)'

format(t, { feat: "omit" });       // 'Wilkinson - Afterglow (Sub Focus VIP Remix)'
format(t, { versions: "none" });   // 'Wilkinson ft. Becky Hill & Tom Cane - Afterglow'
format(t, { position: true });     // '01. Wilkinson ft. Becky Hill & Tom Cane - Afterglow (Sub Focus VIP Remix)'

format(parse("Future - Mask Off (prod. by Metro Boomin)"), { producers: false });
// 'Future - Mask Off'
```

<TabItem label="Rust">

- `.feat(FeatPlacement::Title)`: `Source`, `Artist`, `Title` or `Omit`
- `.feat_marker("featuring")`
- `.joiners(JoinerStyle::Canonical)`: `Original` or `Canonical`
- `.versions(VersionsOption::None)`: `All` or `None`
- `.producers(false)`, `.position(true)`, `.label(false)`

```rust
use trackparse::{format_track_with, FeatPlacement, FormatOptions, JoinerStyle, VersionsOption};

format_track_with(&t, &FormatOptions::new().feat(FeatPlacement::Title));
// "Wilkinson - Afterglow (ft. Becky Hill & Tom Cane) (Sub Focus VIP Remix)"

format_track_with(&t, &FormatOptions::new().feat(FeatPlacement::Title).joiners(JoinerStyle::Canonical));
// "Wilkinson - Afterglow (feat. Becky Hill & Tom Cane) (Sub Focus VIP Remix)"

format_track_with(&t, &FormatOptions::new().feat(FeatPlacement::Artist).feat_marker("featuring"));
// "Wilkinson featuring Becky Hill & Tom Cane - Afterglow (Sub Focus VIP Remix)"

format_track_with(&t, &FormatOptions::new().feat(FeatPlacement::Omit));
// "Wilkinson - Afterglow (Sub Focus VIP Remix)"
format_track_with(&t, &FormatOptions::new().versions(VersionsOption::None));
// "Wilkinson ft. Becky Hill & Tom Cane - Afterglow"
format_track_with(&t, &FormatOptions::new().position(true));
// "01. Wilkinson ft. Becky Hill & Tom Cane - Afterglow (Sub Focus VIP Remix)"

format_track_with(
    &parse("Future - Mask Off (prod. by Metro Boomin)"),
    &FormatOptions::new().producers(false),
);
// "Future - Mask Off"
```

<TabItem label="Go">

- `Feat: trackparse.FeatTitle`: `FeatSource`, `FeatArtist`, `FeatTitle` or `FeatOmit`

- `Joiners: trackparse.JoinersCanonical`: `JoinersOriginal` or `JoinersCanonical`

## Labels

A [label after a bullet](/trackparse/guides/junk-and-flags/#labels-after-a-bullet) is written back
after the versions and producers, as `" • " + label`. Notes are junk, so they are not
([try it](/trackparse/playground/#track=Noisia%20-%20concussion%20%E2%80%A2%20VISION%20%E2%80%A2%20VISION%20RADIO%20RELOAD)):

<Tabs syncKey="lang">
<TabItem label="JavaScript">

```js
const l = parse("Noisia - concussion • VISION • VISION RADIO RELOAD");
format(l);                     // 'Noisia - concussion • VISION'
format(l, { label: false });   // 'Noisia - concussion'
```

</TabItem>
<TabItem label="Python">

```python
l = parse("Noisia - concussion • VISION • VISION RADIO RELOAD")
format_track(l)                # 'Noisia - concussion • VISION'
format_track(l, label=False)   # 'Noisia - concussion'
```

</TabItem>
<TabItem label="Rust">

```rust
let l = parse("Noisia - concussion • VISION • VISION RADIO RELOAD");
format_track(&l);                                         // "Noisia - concussion • VISION"
format_track_with(&l, &FormatOptions::new().label(false)); // "Noisia - concussion"
```

</TabItem>
<TabItem label="Go">

```go
l := trackparse.Parse("Noisia - concussion • VISION • VISION RADIO RELOAD")
fmt.Printf("%q\n", trackparse.Format(l))                                            // "Noisia - concussion • VISION"
fmt.Printf("%q\n", trackparse.FormatWith(l, trackparse.FormatOptions{OmitLabel: true})) // "Noisia - concussion"
```

</TabItem>
<TabItem label="C">

```c

                                       TRACKPARSE_NUL_TERMINATED);

trackparse_string_free(s);

s = trackparse_format_with(l, o);
printf("%s\n", s->str.ptr);   // Noisia - concussion
trackparse_string_free(s);
trackparse_format_options_free(o);
trackparse_track_free(l);
```

## Round trip

Parsing the formatted string gives back the same artist names and roles, the same title, the
same version types and remixers and the same label, as long as the first parse raised no warnings. The spec makes this
an invariant ([R11.6](/trackparse/reference/spec/#r11-format:~:text=R11.6%20Round%2Dtrip)), and the
[property tests](/trackparse/project/testing/#properties) check it on generated input:

<Tabs syncKey="lang">
<TabItem label="JavaScript">

```js
const s = "Noisia feat. Foreign Beggars - Shellshock (Phace Remix)";
// same artists, title and versions as parse(s):
const again = parse(format(parse(s)));
again.fullTitle;   // 'Shellshock (Phace Remix)'
```

</TabItem>
<TabItem label="Python">

```python
s = "Noisia feat. Foreign Beggars - Shellshock (Phace Remix)"
# same artists, title and versions as parse(s):
again = parse(format_track(parse(s)))
again.full_title   # 'Shellshock (Phace Remix)'
```

</TabItem>
<TabItem label="Rust">

```rust
let s = "Noisia feat. Foreign Beggars - Shellshock (Phace Remix)";
// same artists, title and versions as parse(s):
let again = parse(&format_track(&parse(s)));
&again.full_title;   // "Shellshock (Phace Remix)"
```

</TabItem>
<TabItem label="Go">

```go
s := "Noisia feat. Foreign Beggars - Shellshock (Phace Remix)"
// same artists, title and versions as Parse(s):
again := trackparse.Parse(trackparse.Format(trackparse.Parse(s)))
fmt.Printf("%q\n", again.FullTitle)   // "Shellshock (Phace Remix)"
```

</TabItem>
<TabItem label="C">

```c
const char *in = "Noisia feat. Foreign Beggars - Shellshock (Phace Remix)";
/* same artists, title and versions as trackparse_parse(in, ...): */
trackparse_track *first = trackparse_parse(in, TRACKPARSE_NUL_TERMINATED);
trackparse_string *written = trackparse_format(first);
trackparse_track *again = trackparse_parse(written->str.ptr, written->str.len);
printf("%s\n", again->full_title.ptr);   // Shellshock (Phace Remix)
trackparse_track_free(again);
trackparse_string_free(written);
trackparse_track_free(first);
```

</TabItem>
</Tabs>

The label has two exceptions: it only comes back when the formatted string has an artist part
and a title. `ID - Stigma • VISION` has an unknown artist, so it formats to `Stigma • VISION`. That
string has no dash, and without one the bullet is not read as a label: the second parse gives the
title `Stigma • VISION`, no label and a [`noSeparator`](/trackparse/reference/warnings/#track-warnings:~:text=noSeparator) warning. `Noisia - [HD] • VISION` has an
empty title (the `[HD]` is junk), so it formats to `Noisia - • VISION`, and a bullet right after
the dash starts no label either: the second parse gives the title `• VISION`.

The [playground](/trackparse/playground/#track=01.%20Wilkinson%20ft.%20Becky%20Hill%20%26%20Tom%20Cane%20-%20Afterglow%20%28Sub%20Focus%20VIP%20Remix%29%20%5BOfficial%20Video%5D)
has a `format()` panel if you want to try the options on this track or your own strings. Its code
view writes the call for each language.
