Every credit in the output is an `Artist`:

<Tabs syncKey="lang">
<TabItem label="JavaScript">

```ts
{ name: string; role: "primary" | "featured" | "producer" | "remixer"; joiner: string | null; source: "artist" | "title" | "version" }
```

</TabItem>
<TabItem label="Python">

```python
Artist(name: str, role: ArtistRole, joiner: Optional[str], source: ArtistSource)
# role: "primary" | "featured" | "producer" | "remixer"; source: "artist" | "title" | "version"
```

</TabItem>
<TabItem label="Rust">

```rust
pub struct Artist {
    pub name: String,
    pub role: ArtistRole,         // Primary | Featured | Remixer | Producer
    pub joiner: Option<String>,
    pub source: ArtistSource,     // Artist | Title | Version
}
```

</TabItem>
<TabItem label="Go">

```go
type Artist struct {
	Name   string
	Role   Role     // RolePrimary | RoleFeatured | RoleRemixer | RoleProducer
	Joiner *string  // nil for the first name of a list
	Source Source   // SourceArtist | SourceTitle | SourceVersion
}
```

</TabItem>
</Tabs>

`role` says what the person did. `joiner` is the text that introduced the name, exactly as written
(`"&"`, `","`, `"ft."`, `"prod. by"`), and `null` for the first name of a list (`None` in Python and
Rust, `nil` in Go, where `Joiner` is a `*string`). `source` says where the credit was found: left of the dash (`artist`), right of it (`title`),
or inside a version (`version`). In Rust, `role` and `source` are the enums
[`ArtistRole`](https://docs.rs/trackparse/latest/trackparse/enum.ArtistRole.html) and [`ArtistSource`](https://docs.rs/trackparse/latest/trackparse/enum.ArtistSource.html);
`as_str()` and `Display` give the lowercase names used here. In Go they are the string types
[`Role`](https://pkg.go.dev/github.com/4matic/trackparse/go#Role) and [`Source`](https://pkg.go.dev/github.com/4matic/trackparse/go#Source), with constants such as `trackparse.RolePrimary`
and `trackparse.SourceTitle` whose values are those names. The full field list is under
[`Artist`](/trackparse/reference/parse/#artist) in the reference.

Remixers live inside `versions`, not in `artists`. Use [`allArtists(track)`](/trackparse/reference/functions/#allartiststrack)
(`all_artists` in Python and Rust, `AllArtists` in Go) when you want everyone in one list.

## Joiners

`&`, `x`, `vs.`, `,`, `;`, `+`, `/` and `and` separate names. They're joiners, not roles: every name
they produce is still primary.

<Tabs syncKey="lang">
<TabItem label="JavaScript">

```js
import { parse, parseArtists } from "trackparse";

parse("Skrillex & Diplo x Justin Bieber - Where Are Ü Now").artists.map((a) => [a.name, a.joiner, a.role]);
// [ [ 'Skrillex', null, 'primary' ], [ 'Diplo', '&', 'primary' ], [ 'Justin Bieber', 'x', 'primary' ] ]

parse("Kanye West vs. Daft Punk - Stronger").artists.map((a) => a.name);
// [ 'Kanye West', 'Daft Punk' ]
```

</TabItem>
<TabItem label="Python">

```python
from trackparse import parse, parse_artists

[(a.name, a.joiner, a.role) for a in parse("Skrillex & Diplo x Justin Bieber - Where Are Ü Now").artists]
# [('Skrillex', None, 'primary'), ('Diplo', '&', 'primary'), ('Justin Bieber', 'x', 'primary')]

[a.name for a in parse("Kanye West vs. Daft Punk - Stronger").artists]
# ['Kanye West', 'Daft Punk']
```

</TabItem>
<TabItem label="Rust">

```rust
use trackparse::{parse, parse_artists, parse_artists_with, parse_with, ParseOptions, SplitAnd};

parse("Skrillex & Diplo x Justin Bieber - Where Are Ü Now")
    .artists.iter().map(|a| (&a.name, &a.joiner, a.role)).collect::<Vec<_>>();
// [("Skrillex", None, Primary), ("Diplo", Some("&"), Primary), ("Justin Bieber", Some("x"), Primary)]

parse("Kanye West vs. Daft Punk - Stronger").artists.iter().map(|a| &a.name).collect::<Vec<_>>();
// ["Kanye West", "Daft Punk"]
```

</TabItem>
<TabItem label="Go">

```go
import (
	"fmt"

	"github.com/4matic/trackparse/go"
)

names := func(artists []trackparse.Artist) []string {
	out := []string{}
	for _, a := range artists {
		out = append(out, a.Name)
	}
	return out
}

for _, a := range trackparse.Parse("Skrillex & Diplo x Justin Bieber - Where Are Ü Now").Artists {
	if a.Joiner == nil {
		fmt.Println(a.Name, "(joiner nil),", a.Role)
	} else {
		fmt.Printf("%s (joiner %q), %s\n", a.Name, *a.Joiner, a.Role)
	}
}
// Skrillex (joiner nil), primary
// Diplo (joiner "&"), primary
// Justin Bieber (joiner "x"), primary

fmt.Printf("%q\n", names(trackparse.Parse("Kanye West vs. Daft Punk - Stronger").Artists))
// ["Kanye West" "Daft Punk"]
```

</TabItem>
</Tabs>

Some things look like joiners and aren't:

- An unspaced `/`, `&` or `+` never splits. `AC/DC` and `Drum&Bass` stay whole.
- `x` only splits in lowercase, so `Malcolm X` keeps its X.
- `& Sons`, `& Co.`, `& His Orchestra` and a few others never start a new artist. The list is in
  [`no-split-before.json`](https://github.com/4matic/trackparse/blob/main/spec/data/no-split-before.json).
- A comma between two digits (`1,000`) is part of the name.

The rules for the artist side are [R7](/trackparse/reference/spec/#r7-artist-side) in the spec, and
the splitting itself is [R7.3](/trackparse/reference/spec/#r7-artist-side:~:text=R7.3%20Credit%2Dlist%20splitting). Open the
[first example](/trackparse/playground/#track=Skrillex%20%26%20Diplo%20x%20Justin%20Bieber%20-%20Where%20Are%20%C3%9C%20Now)
in the playground to see every joiner.

### `and` is special

`and` is common inside band names, so by default it only splits after a comma has already split the
same list:

<Tabs syncKey="lang">
<TabItem label="JavaScript">

```js
parse("Simon and Garfunkel - The Boxer").artists.map((a) => a.name);
// [ 'Simon and Garfunkel' ]

parseArtists("Crosby, Stills, Nash and Young").map((a) => a.name);
// [ 'Crosby', 'Stills', 'Nash', 'Young' ]
```

</TabItem>
<TabItem label="Python">

```python
[a.name for a in parse("Simon and Garfunkel - The Boxer").artists]
# ['Simon and Garfunkel']

[a.name for a in parse_artists("Crosby, Stills, Nash and Young")]
# ['Crosby', 'Stills', 'Nash', 'Young']
```

</TabItem>
<TabItem label="Rust">

```rust
parse("Simon and Garfunkel - The Boxer").artists.iter().map(|a| &a.name).collect::<Vec<_>>();
// ["Simon and Garfunkel"]

parse_artists("Crosby, Stills, Nash and Young").iter().map(|a| &a.name).collect::<Vec<_>>();
// ["Crosby", "Stills", "Nash", "Young"]
```

</TabItem>
<TabItem label="Go">

```go
fmt.Printf("%q\n", names(trackparse.Parse("Simon and Garfunkel - The Boxer").Artists))
// ["Simon and Garfunkel"]

fmt.Printf("%q\n", names(trackparse.ParseArtists("Crosby, Stills, Nash and Young")))
// ["Crosby" "Stills" "Nash" "Young"]
```

</TabItem>
</Tabs>

Set [`splitAnd`](/trackparse/reference/options/#parse-options) (`split_and` in Python and Rust,
`SplitAnd` in Go) to `"always"` or `"never"` to change that
([try it](/trackparse/playground/#track=Simon%20and%20Garfunkel%20-%20The%20Boxer&splitAnd=always)):

<Tabs syncKey="lang">
<TabItem label="JavaScript">

```js
parse("Simon and Garfunkel - The Boxer", { splitAnd: "always" }).artists.map((a) => a.name);
// [ 'Simon', 'Garfunkel' ]

parseArtists("Crosby, Stills, Nash and Young", { splitAnd: "never" }).map((a) => a.name);
// [ 'Crosby', 'Stills', 'Nash and Young' ]
```

</TabItem>
<TabItem label="Python">

```python
[a.name for a in parse("Simon and Garfunkel - The Boxer", split_and="always").artists]
# ['Simon', 'Garfunkel']

[a.name for a in parse_artists("Crosby, Stills, Nash and Young", split_and="never")]
# ['Crosby', 'Stills', 'Nash and Young']
```

</TabItem>
<TabItem label="Rust">

```rust
let always = ParseOptions::new().split_and(SplitAnd::Always);
parse_with("Simon and Garfunkel - The Boxer", &always).artists.iter().map(|a| &a.name).collect::<Vec<_>>();
// ["Simon", "Garfunkel"]

let never = ParseOptions::new().split_and(SplitAnd::Never);
parse_artists_with("Crosby, Stills, Nash and Young", &never).iter().map(|a| &a.name).collect::<Vec<_>>();
// ["Crosby", "Stills", "Nash and Young"]
```

</TabItem>
<TabItem label="Go">

```go
always := trackparse.ParseOptions{SplitAnd: trackparse.SplitAndAlways}
fmt.Printf("%q\n", names(trackparse.ParseWith("Simon and Garfunkel - The Boxer", always).Artists))
// ["Simon" "Garfunkel"]

never := trackparse.ParseOptions{SplitAnd: trackparse.SplitAndNever}
fmt.Printf("%q\n", names(trackparse.ParseArtistsWith("Crosby, Stills, Nash and Young", never)))
// ["Crosby" "Stills" "Nash and Young"]
```

</TabItem>
</Tabs>

## Features

`feat.`, `ft.` and `featuring` work on either side of the dash and in brackets. `with` and `w/`
only count at the start of a bracket, since "with" turns up in plenty of titles. All of these give
the second name the role `featured`. In a bracket the rule is
[R5.2](/trackparse/reference/spec/#r5-group-classification:~:text=R5.2%20Feat), left of the dash
[R7.2](/trackparse/reference/spec/#r7-artist-side:~:text=R7.2%20Unbracketed%20feat) and right of it
[R8.3](/trackparse/reference/spec/#r8-title-side:~:text=R8.3%20Unbracketed%20feat):

<Tabs syncKey="lang">
<TabItem label="JavaScript">

```js
parse("Noisia feat. Foreign Beggars - Shellshock").artists[1];
// { name: 'Foreign Beggars', role: 'featured', joiner: 'feat.', source: 'artist' }
parse("Noisia - Shellshock ft. Foreign Beggars").artists[1];
// { name: 'Foreign Beggars', role: 'featured', joiner: 'ft.', source: 'title' }
parse("Silk City - Electricity (with Dua Lipa)").artists[1];
// { name: 'Dua Lipa', role: 'featured', joiner: 'with', source: 'title' }
```

</TabItem>
<TabItem label="Python">

```python
parse("Noisia feat. Foreign Beggars - Shellshock").artists[1]
# Artist(name='Foreign Beggars', role='featured', joiner='feat.', source='artist')
parse("Noisia - Shellshock ft. Foreign Beggars").artists[1]
# Artist(name='Foreign Beggars', role='featured', joiner='ft.', source='title')
parse("Silk City - Electricity (with Dua Lipa)").artists[1]
# Artist(name='Dua Lipa', role='featured', joiner='with', source='title')
```

</TabItem>
<TabItem label="Rust">

```rust
&parse("Noisia feat. Foreign Beggars - Shellshock").artists[1];
// Artist { name: "Foreign Beggars", role: Featured, joiner: Some("feat."), source: Artist }
&parse("Noisia - Shellshock ft. Foreign Beggars").artists[1];
// Artist { name: "Foreign Beggars", role: Featured, joiner: Some("ft."), source: Title }
&parse("Silk City - Electricity (with Dua Lipa)").artists[1];
// Artist { name: "Dua Lipa", role: Featured, joiner: Some("with"), source: Title }
```

</TabItem>
<TabItem label="Go">

```go
for _, s := range []string{
	"Noisia feat. Foreign Beggars - Shellshock",
	"Noisia - Shellshock ft. Foreign Beggars",
	"Silk City - Electricity (with Dua Lipa)",
} {
	a := trackparse.Parse(s).Artists[1]
	fmt.Printf("%q %s %q %s\n", a.Name, a.Role, *a.Joiner, a.Source)
}
// "Foreign Beggars" featured "feat." artist
// "Foreign Beggars" featured "ft." title
// "Dua Lipa" featured "with" title
```

</TabItem>
</Tabs>

If the same person is credited twice, they appear once:

<Tabs syncKey="lang">
<TabItem label="JavaScript">

```js
parse("Noisia feat. Foreign Beggars - Shellshock (feat. Foreign Beggars)").artists.map((a) => a.name);
// [ 'Noisia', 'Foreign Beggars' ]
```

</TabItem>
<TabItem label="Python">

```python
[a.name for a in parse("Noisia feat. Foreign Beggars - Shellshock (feat. Foreign Beggars)").artists]
# ['Noisia', 'Foreign Beggars']
```

</TabItem>
<TabItem label="Rust">

```rust
parse("Noisia feat. Foreign Beggars - Shellshock (feat. Foreign Beggars)")
    .artists.iter().map(|a| &a.name).collect::<Vec<_>>();
// ["Noisia", "Foreign Beggars"]
```

</TabItem>
<TabItem label="Go">

```go
fmt.Printf("%q\n", names(trackparse.Parse("Noisia feat. Foreign Beggars - Shellshock (feat. Foreign Beggars)").Artists))
// ["Noisia" "Foreign Beggars"]
```

</TabItem>
</Tabs>

Names are compared with full Unicode case folding and accents removed, so `Sigur Rós` and
`SIGUR ROS` count as the same artist
([R9.2](/trackparse/reference/spec/#r9-assembly-and-dedup:~:text=R9.2%20Dedup)). [Try the
example](/trackparse/playground/#track=Noisia%20feat.%20Foreign%20Beggars%20-%20Shellshock%20%28feat.%20Foreign%20Beggars%29)
in the playground.

## Producers

`prod.`, `prod. by` and `produced by` credit a producer, in brackets
([R5.3](/trackparse/reference/spec/#r5-group-classification:~:text=R5.3%20Producer)) or after the title
([R8.3](/trackparse/reference/spec/#r8-title-side:~:text=R8.3%20Unbracketed%20feat)). The producer gets the role `producer` and
leaves the title:

<Tabs syncKey="lang">
<TabItem label="JavaScript">

```js
const t = parse("Future - Mask Off (prod. by Metro Boomin)");
t.artists[1];  // { name: 'Metro Boomin', role: 'producer', joiner: 'prod. by', source: 'title' }
t.title;       // 'Mask Off'
```

</TabItem>
<TabItem label="Python">

```python
t = parse("Future - Mask Off (prod. by Metro Boomin)")
t.artists[1]  # Artist(name='Metro Boomin', role='producer', joiner='prod. by', source='title')
t.title       # 'Mask Off'
```

</TabItem>
<TabItem label="Rust">

```rust
let t = parse("Future - Mask Off (prod. by Metro Boomin)");
&t.artists[1];  // Artist { name: "Metro Boomin", role: Producer, joiner: Some("prod. by"), source: Title }
&t.title;       // "Mask Off"
```

</TabItem>
<TabItem label="Go">

```go
t := trackparse.Parse("Future - Mask Off (prod. by Metro Boomin)")
a := t.Artists[1]
fmt.Printf("%q %s %q %s\n", a.Name, a.Role, *a.Joiner, a.Source)   // "Metro Boomin" producer "prod. by" title
fmt.Printf("%q\n", t.Title)                                         // "Mask Off"
```

</TabItem>
</Tabs>

## knownArtists

*(Python and Rust: `known_artists`; Go: `KnownArtists`)*

trackparse has no artist database, on purpose. A built-in list would be wrong for half its users
and out of date within a month. You tell it the names you care about:

<Tabs syncKey="lang">
<TabItem label="JavaScript">

```js
parse("Chase & Status - Baddadan").artists.map((a) => a.name);
// [ 'Chase', 'Status' ]

parse("Chase & Status - Baddadan", { knownArtists: ["Chase & Status"] }).artists.map((a) => a.name);
// [ 'Chase & Status' ]
```

</TabItem>
<TabItem label="Python">

```python
[a.name for a in parse("Chase & Status - Baddadan").artists]
# ['Chase', 'Status']

[a.name for a in parse("Chase & Status - Baddadan", known_artists=["Chase & Status"]).artists]
# ['Chase & Status']
```

</TabItem>
<TabItem label="Rust">

```rust
parse("Chase & Status - Baddadan").artists.iter().map(|a| &a.name).collect::<Vec<_>>();
// ["Chase", "Status"]

let options = ParseOptions::new().known_artists(["Chase & Status"]);
parse_with("Chase & Status - Baddadan", &options).artists.iter().map(|a| &a.name).collect::<Vec<_>>();
// ["Chase & Status"]
```

</TabItem>
<TabItem label="Go">

```go
fmt.Printf("%q\n", names(trackparse.Parse("Chase & Status - Baddadan").Artists))
// ["Chase" "Status"]

options := trackparse.ParseOptions{KnownArtists: []string{"Chase & Status"}}
fmt.Printf("%q\n", names(trackparse.ParseWith("Chase & Status - Baddadan", options).Artists))
// ["Chase & Status"]
```

</TabItem>
</Tabs>

A known name is matched case- and accent-insensitively wherever a credit list starts. It also
protects names that begin with digits from being read as a track number (`3 Doors Down`). If you
parse a lot of strings with the same names, put them in
[`createParser`](/trackparse/reference/functions/#createparseroptions) (`create_parser` in Python,
`Parser::new` in Rust, `NewParser` in Go). You can try it in the
[playground](/trackparse/playground/#track=Chase%20%26%20Status%20-%20Baddadan&known=Chase%20%26%20Status).
The option is listed under [Options](/trackparse/reference/options/#parse-options), and the
matching rule is [R7.3](/trackparse/reference/spec/#r7-artist-side:~:text=R7.3%20Credit%2Dlist%20splitting) (a).

## Unknown artists

`ID` (and `Unknown`, `Untitled`, `?`, `???`) means the track hasn't been announced yet. It doesn't become a name.
The track gets `flags.unknownArtist: true` (`flags.unknown_artist` in Python and Rust,
`Flags.UnknownArtist` in Go) instead, and the same goes for titles
([R7.5](/trackparse/reference/spec/#r7-artist-side:~:text=R7.5%20Drops%20and%20unknowns), [R8.6](/trackparse/reference/spec/#r8-title-side:~:text=R8.6%20Unknown%20title);
[open it in the playground](/trackparse/playground/#track=ID%20-%20ID%20%28ID%20Remix%29)):

<Tabs syncKey="lang">
<TabItem label="JavaScript">

```js
const t = parse("ID - ID (ID Remix)");
t.artists;                    // []
t.flags.unknownArtist;        // true
t.flags.unknownTitle;         // true
t.versions[0].unknownArtist;  // true
```

</TabItem>
<TabItem label="Python">

```python
t = parse("ID - ID (ID Remix)")
t.artists                     # ()
t.flags.unknown_artist        # True
t.flags.unknown_title         # True
t.versions[0].unknown_artist  # True
```

</TabItem>
<TabItem label="Rust">

```rust
let t = parse("ID - ID (ID Remix)");
&t.artists;                    // []
t.flags.unknown_artist;        // true
t.flags.unknown_title;         // true
t.versions[0].unknown_artist;  // true
```

</TabItem>
<TabItem label="Go">

```go
t = trackparse.Parse("ID - ID (ID Remix)")
fmt.Println(len(t.Artists))                  // 0
fmt.Println(t.Flags.UnknownArtist)           // true
fmt.Println(t.Flags.UnknownTitle)            // true
fmt.Println(t.Versions[0].UnknownArtist)     // true
```

</TabItem>
</Tabs>
