## Junk

Junk is everything that describes the upload and not the song. It leaves the title, and it goes
into `junk` with a kind so you can decide what to do with it. You can open the example below in the
[playground](/trackparse/playground/#track=Daft%20Punk%20-%20One%20More%20Time%20%28Official%20Music%20Video%29%20%5BHD%5D).

<Tabs syncKey="lang">
<TabItem label="JavaScript">

```js
import { parse } from "trackparse";

const t = parse("Daft Punk - One More Time (Official Music Video) [HD]");
t.title;  // 'One More Time'
t.junk;   // [ { raw: 'Official Music Video', kind: 'video' }, { raw: 'HD', kind: 'quality' } ]
```

</TabItem>
<TabItem label="Python">

```python
from trackparse import parse

t = parse("Daft Punk - One More Time (Official Music Video) [HD]")
t.title  # 'One More Time'
t.junk   # (Junk(raw='Official Music Video', kind='video'), Junk(raw='HD', kind='quality'))
```

</TabItem>
<TabItem label="Rust">

```rust
use trackparse::parse;

let t = parse("Daft Punk - One More Time (Official Music Video) [HD]");
&t.title;  // "One More Time"
&t.junk;   // [Junk { raw: "Official Music Video", kind: Video }, Junk { raw: "HD", kind: Quality }]
```

</TabItem>
<TabItem label="Go">

```go
import (
    "fmt"

    "github.com/4matic/trackparse/go"
)

t := trackparse.Parse("Daft Punk - One More Time (Official Music Video) [HD]")
fmt.Printf("%q\n", t.Title)   // "One More Time"
fmt.Printf("%+v\n", t.Junk)   // [{Raw:Official Music Video Kind:video} {Raw:HD Kind:quality}]
```

</TabItem>
</Tabs>

| Kind | Examples |
|---|---|
| `video` | `Official Video`, `Official Music Video`, `Visualizer` |
| `audio` | `Official Audio`, `Audio` |
| `lyrics` | `Lyrics`, `Lyric Video` |
| `quality` | `HD`, `HQ`, `4K`, `1080p` |
| `promo` | `Free Download`, `Out Now`, `Premiere` |
| `platform` | `- YouTube`, `- SoundCloud` suffixes |
| `label` | `NCS Release`, `Monstercat Release` |
| `genre` | a bracketed genre such as `[Drum & Bass]` |
| `other` | a bare `(Official)` |

The phrases are in [`junk.json`](https://github.com/4matic/trackparse/blob/main/spec/data/junk.json)
(plus `genres.json` for the genre kind) and [`platform-suffixes.json`](https://github.com/4matic/trackparse/blob/main/spec/data/platform-suffixes.json).
Seeing junk is also one of the ways `mode: "auto"` decides a string came from YouTube
(see [Modes](/trackparse/guides/modes/#how-auto-decides)).

In Rust the kind is the enum `JunkKind` (`JunkKind::Video`, `JunkKind::Quality` and so on). Its
`as_str()` gives the lowercase names in the table. In Go the kind is the string type `JunkKind`,
and its constants (`trackparse.JunkKindVideo`, `trackparse.JunkKindQuality`) hold those names.

<Tabs syncKey="lang">
<TabItem label="JavaScript">

```js
parse("Porter Robinson - Shelter - YouTube").junk;   // [ { raw: 'YouTube', kind: 'platform' } ]
parse("Elektronomia - Sky High [NCS Release]").junk; // [ { raw: 'NCS Release', kind: 'label' } ]
```

</TabItem>
<TabItem label="Python">

```python
parse("Porter Robinson - Shelter - YouTube").junk   # (Junk(raw='YouTube', kind='platform'),)
parse("Elektronomia - Sky High [NCS Release]").junk # (Junk(raw='NCS Release', kind='label'),)
```

</TabItem>
<TabItem label="Rust">

```rust
parse("Porter Robinson - Shelter - YouTube").junk;   // [Junk { raw: "YouTube", kind: Platform }]
parse("Elektronomia - Sky High [NCS Release]").junk; // [Junk { raw: "NCS Release", kind: Label }]
```

</TabItem>
<TabItem label="Go">

```go
fmt.Printf("%+v\n", trackparse.Parse("Porter Robinson - Shelter - YouTube").Junk)     // [{Raw:YouTube Kind:platform}]
fmt.Printf("%+v\n", trackparse.Parse("Elektronomia - Sky High [NCS Release]").Junk)   // [{Raw:NCS Release Kind:label}]
```

</TabItem>
</Tabs>

Catalog numbers like `[HOSP123]` are not junk yet. They stay in the title. See the
[roadmap](/trackparse/project/roadmap/).

To treat a phrase of your own as junk, add it with
[`keywords.junk`](/trackparse/reference/options/#keywords).

## Flags

<Tabs syncKey="lang">
<TabItem label="JavaScript">

```js
parse("Eminem - Without Me (Explicit)").flags;
// { explicit: true, clean: false, unknownArtist: false, unknownTitle: false }
```

</TabItem>
<TabItem label="Python">

```python
parse("Eminem - Without Me (Explicit)").flags
# Flags(explicit=True, clean=False, unknown_artist=False, unknown_title=False)
```

</TabItem>
<TabItem label="Rust">

```rust
parse("Eminem - Without Me (Explicit)").flags;
// Flags { explicit: true, clean: false, unknown_artist: false, unknown_title: false }
```

</TabItem>
<TabItem label="Go">

```go
fmt.Printf("%+v\n", trackparse.Parse("Eminem - Without Me (Explicit)").Flags)
// {Explicit:true Clean:false UnknownArtist:false UnknownTitle:false}
```

</TabItem>
</Tabs>

`explicit` and `clean` come from `(Explicit)`, `[Clean]` and the like. `unknownArtist` and
`unknownTitle` (`unknown_artist` and `unknown_title` in Python and Rust, `UnknownArtist` and `UnknownTitle` in
Go) are set when the artist
or title is a placeholder such as `ID`. See
[Unknown artists](/trackparse/guides/artists/#unknown-artists).

## Year

A year on its own in brackets, or as a dash suffix, goes into `year`:

<Tabs syncKey="lang">
<TabItem label="JavaScript">

```js
const t = parse("Noisia - Stigma (2015)");
t.title;  // 'Stigma'
t.year;   // 2015
```

</TabItem>
<TabItem label="Python">

```python
t = parse("Noisia - Stigma (2015)")
t.title  # 'Stigma'
t.year   # 2015
```

</TabItem>
<TabItem label="Rust">

```rust
let t = parse("Noisia - Stigma (2015)");
&t.title;  // "Stigma"
t.year;    // Some(2015)
```

</TabItem>
<TabItem label="Go">

```go
t = trackparse.Parse("Noisia - Stigma (2015)")
fmt.Printf("%q\n", t.Title)   // "Stigma"
fmt.Println(*t.Year)          // 2015
```

</TabItem>
</Tabs>

A year inside a version (`Remastered 2015`) belongs to that version instead, in `versions[i].year`.
In Rust both are `Option<u32>`; in Go both are `*int`, `nil` when there is no year.

## Track numbers

<Tabs syncKey="lang">
<TabItem label="JavaScript">

```js
parse("01. Aphex Twin - Xtal").position;   // { raw: '01', number: 1 }
parse("2 Unlimited - No Limit").position;  // null
```

</TabItem>
<TabItem label="Python">

```python
parse("01. Aphex Twin - Xtal").position   # Position(raw='01', number=1)
parse("2 Unlimited - No Limit").position  # None
```

</TabItem>
<TabItem label="Rust">

```rust
parse("01. Aphex Twin - Xtal").position;   // Some(Position { raw: "01", number: 1 })
parse("2 Unlimited - No Limit").position;  // None
```

</TabItem>
<TabItem label="Go">

```go
fmt.Printf("%+v\n", *trackparse.Parse("01. Aphex Twin - Xtal").Position)   // {Raw:01 Number:1}
fmt.Println(trackparse.Parse("2 Unlimited - No Limit").Position == nil)    // true
```

</TabItem>
</Tabs>

`raw` keeps the digits as written, so you can tell `01` from `1`. These count as track numbers:

- a number followed by `.` or `)`: `01. Title`, `1) Intro`;
- a zero-padded number and a space: `01 Aphex Twin - Xtal`;
- a number and a dash, when another dash follows: `3 - Artist - Title`;
- in file names, also `07_Burial`, `01-Track` and `3 My Song.mp3`.

A plain number before a word is part of the name: `2 Unlimited`, `50 Cent`, `808 State`. The rule
is [R4](/trackparse/reference/spec/#r4-prefixes-timestamp-and-position). In a tracklist, a bare
number can still count when the lines around it continue the sequence: see
[Bare track numbers](/trackparse/guides/tracklists/#bare-track-numbers).

## Cue times

A time at the start becomes `timestamp`, with the seconds worked out for you:

<Tabs syncKey="lang">
<TabItem label="JavaScript">

```js
parse("[12:34] Noisia - Stigma").timestamp;   // { raw: '12:34', seconds: 754 }
parse("1:02:03 Noisia - Stigma").timestamp;   // { raw: '1:02:03', seconds: 3723 }
```

</TabItem>
<TabItem label="Python">

```python
parse("[12:34] Noisia - Stigma").timestamp   # Timestamp(raw='12:34', seconds=754)
parse("1:02:03 Noisia - Stigma").timestamp   # Timestamp(raw='1:02:03', seconds=3723)
```

</TabItem>
<TabItem label="Rust">

```rust
parse("[12:34] Noisia - Stigma").timestamp;   // Some(Timestamp { raw: "12:34", seconds: 754 })
parse("1:02:03 Noisia - Stigma").timestamp;   // Some(Timestamp { raw: "1:02:03", seconds: 3723 })
```

</TabItem>
<TabItem label="Go">

```go
fmt.Printf("%+v\n", *trackparse.Parse("[12:34] Noisia - Stigma").Timestamp)   // {Raw:12:34 Seconds:754}
fmt.Printf("%+v\n", *trackparse.Parse("1:02:03 Noisia - Stigma").Timestamp)   // {Raw:1:02:03 Seconds:3723}
```

</TabItem>
</Tabs>

For whole tracklists with a time on every line, use [`parseTracklist`](/trackparse/guides/tracklists/)
(`parse_tracklist` in Python and Rust, `ParseTracklist` in Go) instead. It reads more time formats and checks the order.
